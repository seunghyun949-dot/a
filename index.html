모델 가정: 이 앱은 실험 조건 비교용 근사 모델입니다. 실제 DC→고전압 승압에는 내부 스위칭 회로가 필요하며, 실제 출력은 코어 포화, 누설 인덕턴스, 절연, 부하, 습도, 전극 표면 상태 등에 따라 달라질 수 있습니다. 코로나·추력·풍속 값은 절대 예측값보다는 상대 비교용으로 사용하고, 실제 측정값으로 보정하는 것을 권장합니다. Ksw·αcoil·αCW는 실측 사양이나 전력 효율이 아닌 전압 모델의 추정 계수입니다. Vpk는 대칭 AC 등가 피크(입력 전압 스윙의 절반)로 가정하며, 실제 비대칭 플라이백 파형에는 그대로 적용되지 않을 수 있습니다. C 2개와 D 2개를 한 단으로 하는 반파 CW 연결을 가정합니다. 단순 직렬·병렬 연결에는 이 단수 규칙을 적용하지 않습니다. 주파수·듀티·리플·부하 전압강하는 계산하지 않으므로 용량 C는 현재 저장 에너지 계산에만 반영됩니다. 요구 전력이 입력 전력 상한을 넘으면 코로나 상태를 판정 보류하고 전류·추력·풍속은 계산 불가로 표시합니다. 상한 전류를 실제 전류로 대입하지 않습니다. 부하 전압·전류 실측값 또는 전원 부하 특성 없이는 해당 조건의 실제 풍속을 예측할 수 없습니다. 전력 상한 미도달 값도 미보정 경험식의 비교값입니다.

고전압 주의: 출력과 커패시터 잔류 전하는 감전·아크 위험이 있습니다. 이 화면의 정격·전계 표시는 안전 판정이 아닙니다. 입력 0–15 V 조절 범위는 실제 모듈의 허용 입력 범위를 뜻하지 않습니다. 실물 사양과 절연·방전 상태를 별도로 확인해야 합니다.
