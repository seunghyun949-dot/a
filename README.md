# ALPHA HV Converter & Ion Wind Simulator

알파프로젝트용 **고전압 컨버터 + EHD(이온풍) 실험 비교 시뮬레이터**입니다.

## 주요 기능

- DC 파워서플라이 전압: **0 ~ 15 V, 0.01 V 단위**
- 전류 제한: **0 ~ 8 A, 0.01 A 단위**
- 1차 / 2차 권선수 조절
- 스위칭 / 플라이백 계수 Ksw 조절 (추정값)
- 코일 / CW 전압 전달계수 조절 (추정값, 전력 효율과 구분)
- 커패시터 용량 / 정격전압 설정
- 커패시터 개수 선택 → CW 단수 자동 계산 (4개 = 2단)
- 권선비 / 유효 HV 승압비, 코일 피크 / CW 이상적 무부하 / 보정 HV 출력 구분
- Emitter 형태, 반경, 전극 간격, 유효 유동 면적 조절
- 추정 HV 출력
- 코로나 개시 여부
- 추정 코로나 전류
- 이론 추력(mN, gf)
- 등가 평균 풍속(m/s)
- 아크 위험 구간 표시
- 실험 조건 저장
- 결과 복사
- CSV 내보내기
- 전체 시스템 모식도 실시간 갱신

## 사용 방법

`index.html`을 브라우저에서 열면 바로 실행됩니다.  
별도의 서버나 Python 설치가 필요하지 않습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
   - 예: `alpha-hv-ionwind-simulator`
2. 이 폴더의 `index.html`, `README.md`, `MODEL_NOTES.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. 배포 소스를 `Deploy from a branch`로 선택합니다.
5. Branch를 `main`, Folder를 `/ (root)`로 선택한 뒤 저장합니다.
6. 생성된 GitHub Pages 주소를 팀원에게 공유하면 됩니다.

보통 주소 형태는 다음과 같습니다.

`https://<github-id>.github.io/alpha-hv-ionwind-simulator/`

## 주의

이 프로그램은 **정밀 SPICE / FEM / CFD 시뮬레이터가 아닙니다.**

현재 모델은 입력 조건 변화에 따른 경향 비교를 위한 근사 모델입니다.
실제 결과는 다음 요소에 크게 영향을 받습니다.

- 내부 스위칭 주파수와 듀티
- 코어 재질과 포화
- 누설 인덕턴스
- 권선 저항
- 정류 소자 특성
- 커패시터 ESR
- 절연 / 기생 커패시턴스
- 실제 부하
- 온도 / 습도 / 압력
- 전극 표면 상태 및 형상

실제 실험에서 **HV 출력, 코로나 전류, 풍속 또는 추력**을 측정한 뒤 보정계수를 맞추면 프로젝트 전용 모델로 개선할 수 있습니다.

## 버전

v0.2

기본값: 3.7 V, 1.5 A, Np=1, Ns=100, Ksw=10, 1 nF / 20 kV ×4.
기본 보정 HV는 6,734 V이며 실제 부하 출력의 보증값이 아닙니다.
전체 모델 가정, 전력 상한, 미반영 요소 및 참고자료는 `MODEL_NOTES.md`를 참조하세요.

## 변경 사항

- 기존 4열 카드·SVG·모바일 배치를 유지했습니다.
- Ksw, 커패시터 개수, 자동 CW 단수를 결과 복사·저장·CSV에 반영했습니다.
- 커패시터 비교를 이상적 최대 소자 전압 기준으로, 저장 에너지를 CW 전체 합 기준으로 수정했습니다.
- 전원 입력이 0이면 지속 출력은 0이며, 추정 코로나 전류에 입력 전력 상한을 적용합니다.
- 용량 C는 저장 에너지에 반영됩니다. 주파수·부하 입력이 없어 리플과 부하 전압강하는 해석하지 않습니다.
- 고전압·잔류 전하 위험과 모델 한계를 화면에 표시합니다.

## 개발 검증 (실행에는 불필요)

Node.js와 Playwright, Microsoft Edge가 설치된 환경에서:

```sh
npm install --no-save playwright
node --test tests/simulator.cjs
```

Chrome 사용 시 `BROWSER_CHANNEL=chrome` 환경변수를 지정할 수 있습니다.
별도 빌드 단계 없이 `index.html`을 열어 사용합니다.
